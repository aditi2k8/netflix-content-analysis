# Netflix Content Analysis Dashboard 🎬

## Overview
Exploratory data analysis and interactive visualization of 8,800+ Netflix titles across 190+ countries, uncovering trends in content production, genre popularity, and global distribution.

## Key Findings
1. Netflix is 70% Movies, 30% TV Shows
2. 2019 was Netflix's peak year
3. USA leads content production but India is #2
4. International Movies is the #1 genre
5. TV-MA dominates ratings
6. Most TV shows have only 1 season
7. Movies are typically 90-100 minutes
